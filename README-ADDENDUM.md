# Game skills — collection entry point

This repository collects reusable guidance and small utilities for procedural village/city builders and browser game development.

Start with the [skill catalog](CATALOG.md). It groups the material by procedural building, gameplay, rendering/WebGPU and browser testing, and preserves each knowledge-base source ID for traceability. Helper scripts are under [`tools/`](tools/README.md).

This addendum is intentionally separate from the repository's existing root README so its content is preserved unchanged. `CATALOG.md` is the entry point for this collection.
