# Helper tools

Scripts copied from the registered helper scripts of the source skills. Run the Python files with Python 3. Their individual `--help`/CLI documentation is authoritative where available.

| Folder | Files | Source skill | Purpose |
|---|---|---|---|
| `platformer/` | `jump_arc_calculator.py`, `movement_tuning.py` | Third-Person Platformer Game Feel (`cmu3jgwla01lw07adabopxymw`) | Derive jump physics and movement curves from design targets. |
| `rendering/` | `bundle_game.py`, `verify_game.py` | Three.js Browser Game Prototyping and Performance (`cmu3jgy8j01ny07adxk47q8jv`) | Bundle a browser game into HTML and run headless verification. |
| `testing/` | `canvas-drag.py`, `canvas-eval.py` | agent-browser CLI for Headless Web and Three.js Testing (`cmumlsr6m08zl07adnacecmi9`) | Automate canvas drags and inspect page/game state with agent-browser. |
| `architecture/` | `compute_geometry.py`, `validate_floorplan.py` | Measurement-Accurate Architectural Modeling in Three.js (`cmue6r1qw0as707ad26gsizq9`) | Compute and validate measurement-driven floor-plan data. |
